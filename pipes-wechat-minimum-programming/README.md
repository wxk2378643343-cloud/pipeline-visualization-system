# 管线定位管理系统-微信小程序前端

本项目是一个基于微信小程序开发的管道与井位空间定位管理系统。旨在为施工现场提供便捷的管网可视化、定位及数据管理方案。通过将复杂的地下管网信息叠加在实时地图上，实现“图纸入口袋，现场见真章”的施工管理目标。

## 🚀 核心功能

*   **实时地理定位**：集成微信官方地图 SDK，实时显示用户当前位置，辅助现场人员快速找正。
*   **管网可视化展示**：
    *   **动态绘制**：根据后端返回的经纬度数据，动态绘制管线（Polyline）与井位（Marker）。
    *   **色标管理**：支持根据管道类型（如雨污水、供电、给水等）和井位型号自定义颜色，直观区分不同属性。
*   **交互式信息查询**：
    *   点击地图上的管道或井位，即可弹出详细的施工参数（深度、管径、材质、型号等）。
    *   支持高效的“就近点位筛选”算法，在大规模数据分布下仍能保持丝滑的点击响应。
*   **数据导入与管理**：
    *   支持在小程序端直接上传 Excel 数据（`.xlsx`, `.xls`），实现现场数据的快速更新。
    *   具备管道类型筛选功能，支持“全部展示”或“按类型选中展示”，减少视觉干扰。
*   **测试与调试模式**：内置测试模式，支持手动输入经纬度进行坐标偏移调试，方便在不同坐标系或误差环境下进行微调。

## 🛠 技术选型

*   **开发语言**：TypeScript
*   **开发框架**：微信小程序原生框架
*   **地图引擎**：微信小程序地图组件 (`map`)

## 📁 目录结构

```text
miniprogram/
├── components/          # 自定义组件 (如坐标偏移调试组件)
├── entity/              # TypeScript 接口与实体类定义
├── libs/                # 外部工具库 (Base64, Gzip 解压等)
├── pages/               # 页面文件
│   └── index/methods/   # 业务逻辑拆分模块 (绘图、点击判定、响应处理等)
├── static/              # 静态资源 (图标、图片)
└── utils/               # 通用工具函数 (计算、定位、网络请求等)
```

## ⚙️ 快速启动

### 1. 环境准备
*   下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
*   准备一个微信小程序 AppID（或使用测试号）。

### 2. 项目导入

1.  打开微信开发者工具，点击 **导入**。
2.  选择 `pipes-wechat-minimum-programming` 根目录。
3.  确认项目名称并填写你的 AppID。

### 3. 配置修改

*   **后端 API**：在 `miniprogram/app.ts` 中修改 `globalData` 下的 `serverHost` 和 `serverPort` 以连接你的服务器。
*   **配置颜色**：可以在 `app.ts` 的 `wellColorMap` 和 `pipeColorMap` 中自定义不同管线的显示颜色。

### 4. 运行调试
*   点击 **编译** 即可在模拟器中查看地图效果。
*   **真机调试**：由于涉及 GPS 定位，建议使用“真机调试”功能在室外环境下测试定位的准确性。
